# SOP Creation Prompts  
Create clear, consistent, and easy‑to‑follow SOPs for your business operations.

These prompts help you turn messy processes into clean documentation your team can actually use.

---

## 🧩 1. Create a Full SOP From Bullet Points
**Prompt:**  
“You are an operations specialist. Turn the following bullet points into a complete SOP with a clear purpose, scope, step‑by‑step instructions, acceptance criteria, and a final checklist. Use a friendly, modern tone. Here are the bullet points: [paste here]”

---

## 🧩 2. Rewrite an Existing SOP for Clarity
**Prompt:**  
“Rewrite the following SOP to be clearer, more concise, and easier to follow. Improve formatting, add step numbers, include acceptance criteria, and create a quick‑start checklist at the end. SOP: [paste here]”

---

## 🧩 3. Create a Daily Operations SOP
**Prompt:**  
“Create a daily operations SOP for a small business. Include: opening tasks, communication expectations, task handoff, documentation standards, and end‑of‑day wrap‑up. Make it simple and repeatable.”

---

## 🧩 4. Create a Role‑Specific SOP
**Prompt:**  
“Create a role‑specific SOP for the position of [role]. Include responsibilities, daily workflow, communication expectations, tools used, and success criteria.”

---

## 🧩 5. Create a Process Improvement SOP
**Prompt:**  
“Write an SOP for improving an existing process. Include: how to identify issues, how to document them, how to propose changes, how to test improvements, and how to update the SOP.”

---

## 🧩 6. Create an SOP Template
**Prompt:**  
“Generate a reusable SOP template with sections for: Purpose, Scope, Tools Needed, Step‑by‑Step Instructions, Acceptance Criteria, Troubleshooting, and a Final Checklist.”

---

## 🧩 7. Add a Quick‑Start Summary
**Prompt:**  
“Add a 3‑sentence quick‑start summary to this SOP so new team members can understand the process at a glance. SOP: [paste here]”
